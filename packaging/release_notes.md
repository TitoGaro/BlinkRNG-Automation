## Descarga e instalación

1. Descarga `BlinkRNG-Automation-…-windows.zip` (en **Assets**, abajo).
2. Descomprímelo donde quieras y abre `BlinkRNG-Automation.exe`. No hace falta instalar Python.
3. La primera vez, Windows puede avisar con «Windows protegió su PC» porque el programa no está firmado: pulsa
   **Más información → Ejecutar de todos modos**.

Necesitas una placa ESP32 con el firmware PABotBase2 y una capturadora. Guías:
[uso](https://github.com/TitoGaro/BlinkRNG-Automation/blob/main/docs/03-guia-puesta-en-marcha.md) ·
[encuentros](https://github.com/TitoGaro/BlinkRNG-Automation/blob/main/docs/guia-encuentros.md).

## Download and install

1. Download `BlinkRNG-Automation-…-windows.zip` (under **Assets**, below).
2. Unzip it anywhere and open `BlinkRNG-Automation.exe`. You do not need to install Python.
3. The first time, Windows may warn with "Windows protected your PC" because the program is not signed: click
   **More info → Run anyway**.

You need an ESP32 board with the PABotBase2 firmware and a capture card. Guides:
[user guide](https://github.com/TitoGaro/BlinkRNG-Automation/blob/main/docs/user-guide.md) ·
[encounters](https://github.com/TitoGaro/BlinkRNG-Automation/blob/main/docs/encounter-guide.md).
